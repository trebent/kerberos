Open-source API gateway · written in Go

Kerberos

One entry point for your backend services. Kerberos routes every request, checks who is calling and what they send, and records what happened, all from one JSON config file.

How Kerberos handles a backend call

Clients call /gw/backend/<name>/<path> on the gateway port. Every call passes through the same stages before it reaches the backend registered as <name>.
